# Game Test

敌人未被阻挡且沿路线距终点不超过 1 格时，受威胁的终点标记闪烁并显示「敌人接近！」；多个终点可同时预警。敌人离场或被阻挡后预警消失，漏怪时顶部基地生命短暂闪红。战斗暂停时预警与闪红冻结；终局后闪红仍会淡出，重开清除提示。表现读取战斗快照和 escape 事件，不改变漏怪规则。真实窗口验证入口为 `game/tests/leak_warning_test.gd`。

从 Developer Hub 进入 Game Test，或在 Godot 中 F6 运行 `game/battle/battle_scene.tscn`。默认项目入口是 Player Mode，开发者脚本显式启动 Hub。Game Test 使用主视口完整显示战场，没有固定宽高比留边和工作区滚动外壳。

F3 调试窗的关卡下拉框保留开发样例，并增加第一章四关；选择后重置战斗，“重新加载关卡”读取已保存的角色／敌人／技能 `.tres`、关卡／波次 CSV、MD 和地图。默认开发样例使用第一章的城市地形、外围和背景，保留自身的地图布局与路线；编队直接引用第一章的五名正式角色。正式章节编辑方式见 `content/campaign/README.md`。

F3 调试窗提供“跳过战斗并胜利”。Player Mode 的开发者模式在战斗左下角直接展开开发者面板，提供相同操作；普通玩家模式不显示面板。Game Test 只展示胜利结果；Player Mode 沿用正常胜利流程记录待播放剧情，战后剧情完成后解锁下一关。面板不改变暂停状态，已结束的战斗不能覆盖结果。

## 操作

1. 准备态可先部署。按住底部干员卡拖到地块松开，角色会站在候选地块进入待部署状态并显示攻击范围。选中部署列表中的干员后，左侧显示头像、同一行的职业图标与角色名、战斗属性、攻击范围及下方的技能说明，切换干员即时刷新，待部署定向时保持显示；取消选择或完成部署后关闭。费用不足时仍可选中并查看干员，但不能部署；尚未部署时不显示释放技能或撤退操作。待部署阶段不显示方向菜单：移动鼠标可预览立片朝向、罗盘与范围；在地块中心向右／下／左／上点击，按该次点击位置确定朝向并立即确认部署，无需方向按钮或第二个确认按钮。中心24像素内点击不部署。角色旁边的撤退图标用于取消本次部署；右键或Esc也可取消。松开在地图外或调试窗中取消拖动。确认前不扣费，取消保留费用和编队，确认后仍由battle验证合法性。单击角色卡不显示可部署格；拖动时绿色高亮表示当前可部署格，合法候选显示橙色攻击范围。松开后绿色高亮消失，定向时保留攻击范围，部署成功后清除。
2. 进入或重开后自动推进：默认第1秒开始路线预告，第3秒生成首批敌人，无需开始按钮。倒计时沿用暂停与倍速时钟。右上角控制暂停，倍速按钮按 1× → 2× → 4× → 1× 循环切换。暂停时允许明确的部署、撤退和技能命令，模拟与表现时钟冻结。
3. 干员脚下常驻生命绿条和技力蓝条，技能开启时增加金色持续时间条，结束后隐藏；敌人只显示生命条。点击在场干员的立片或地块，左侧详情面板显示与部署前相同的角色属性、攻击范围和技能信息，随窗口和内容高度自动居中。干员附近左上角的回转箭头图标用于撤退，右下角技能图标用于释放技能；未就绪、技能持续中或准备态时技能按钮禁用。图标随镜头和窗口尺寸调整位置，取消选择或干员离场时隐藏。部署卡左上角显示对应职业图标（近卫双剑、重装盾牌、射手弓箭、术师法杖、医疗十字），紧邻职业图标右侧显示部署消耗数字，卡片等比显示完整立绘，不显示姓名或额外费用符号；职业图标来自正式class_icons图集切片，由角色外观资源注入，不阻挡点击或拖动。已部署干员立即从右下卡组隐藏，其余卡片靠右收拢；撤退或阵亡后按原编队顺序恢复，冷却遮罩显示倒计时，冷却结束后可选择查看，费用足够才能部署。
4. 终局显示防守成功／基地失守：成功时只显示“继续”，进入战后剧情或返回调用入口；失败时点击“重新挑战”恢复准备态。左上菜单也可重开，或选择“退出战斗”返回；独立运行游戏场景时该操作结束运行。
5. Game Test 左上菜单内的“退出战斗”返回首页。离开工作区释放战斗、角色、特效与观察连接。

F3 或左下角小按钮“F3”打开内嵌小窗：拖标题移动，拖右下角 ◢ 缩放，× 关闭；窗口限制在游戏区域内。工具提供开始、暂停、单步、1×／2×／4×、重置、重新加载关卡、网格／路线／范围、选中单位快照及最近 12 条事件。单步要求运行态且暂停。小窗的鼠标与键盘输入不传给战场，不直接改写模拟内部状态。

## 在编辑器制作关卡

- 打开 `content/scenes/scene_001/map.tscn`，选择 **Terrain / TileMapLayer** 在 2D 编辑器刷图。城市 TileSet 的不可部署高台位于 (1,3)，为浅色地面加黄黑警示边；不可部署地面位于 (2,3)，为深色盖板。两者均不可通行。橡皮擦删除的格子没有 3D 地块且不可部署。
- 图集 `content/terrains/terrain_002/tileset.tres` 的自定义数据：`appearance` 为 R/H/G/W/B/D，`height` 是 3D 顶面高度，`deployment` 为 ground/high/none，`walkable` 表示路线可通行。编辑图集为单格 64×64；实际 3D 渲染使用同目录的城市 atlas。
- 默认地图 bounds 为 `(0,0,10,6)`。地图从零坐标开始，改变大小时同步编辑 bounds。3D 地块、围墙、底座和游戏镜头据此适配；不要将路线穿过水或空格。
- 在 **Routes** 下选择 upper / lower 的 Path2D 编辑折线路径。2D 格心为 `(32+64*x, 32+64*y)`；建议吸附步长 64、偏移 32。控制点必须对齐格心，线段沿横／纵轴，曲线的入／出手柄保持零。路径节点名称即路线 ID，首点是出生点，末点是基地入口；编辑器用红／蓝点标记两端。
- 选根节点的 **Level** 资源，或直接打开同目录 `level.tres`：修改基地生命、费用、上限、敌人和波次。默认编队由 `content/data/game_test_roster.tres` 指定，直接引用正式角色；波次的 time 为绝对战斗时间，enemy 和 route 必须匹配字典键与 Path2D 名称，number 用于显示波次编号。
- 地图根节点的配置警告显示越界、断路、水域、不对齐、非法资源与波次引用。运行时出现配置错误会显示原因并阻止开始，修复后可再次重新加载。
- 保存后打开 `content/scenes/scene_001/preview.tscn` 的 3D 视图。选中 Field，点击 Inspector 的 **刷新 TileMap 的 3D 预览**；该预览也可 F6 运行。它与正式游戏及 Art Test 复用相同地形生成器。
- 在正在运行的 Game Test 中用“重新加载关卡”读取已保存资源，包括外部数值与 TileSet。该操作重置战斗；仅修改尚未保存的编辑器内容不会影响运行中的关卡。

编辑 scene_001 样例时，敌人和波次在 Level 中配置；默认干员使用正式角色的 ActorDefinition 文件。新增正式单位按 content/campaign/README.md 配置并在 actors.tres 注册。数值中的稳定 content_id 用于 game 查找外观；外观资源包含正／背面待机与攻击四种姿态、头像和显示高度。数值不引用贴图，正式模块不加载 Human 原图。

## Art / Game 显示一致性

Art Test 的 Battle 页以模拟快照使用同一表现适配器、角色资源和 HUD。两边共用 battlefield_stage 的构图／光照与原 Art Test 红色敌方入口、蓝色基地线框样式；端点均从 TileMap 编辑场景的路线生成。`game/tests/presentation_parity_test.gd` 使用相同快照检查角色姿态、敌人高度、状态条、卡片显隐、HUD 读数和端点几何一致。工作区外壳不同：Art Test 保留导航与等比预览，Game Test 仍铺满窗口。


部署地形限制：近卫／重装只能部署在地面；射手／术师／医疗只能部署在高台（包括高台草丛）。点击或拖放到错误地形时不会进入待部署状态，并显示地形要求；保留角色卡、不扣费，可继续选择合适地块。最终部署仍由 battle 校验。


攻击表现：远程干员与远程敌人在 attack_start 发射朝目标飞行的子弹，近战单位播放刀光；damage 到来时目标播放受击闪光并短暂变色，命中／miss 清除对应子弹。医疗使用独立绿色治疗特效，技能启动使用强化特效。特效跟随战斗时钟暂停和倍速，重开与退出清理；Art Test Battle 通过同一适配器预览这些事件。真实渲染专项入口 `game/tests/combat_effects_test.gd`，日志 temp/combat_effects.log，截图 temp/verification/combat_projectile.png、combat_slash.png、combat_impact.png。


攻击范围预览使用贴合各地块高度的橙色半透明覆盖层及亮橙边框；合法拖动候选、待部署定向和选中在场干员时显示范围；无效格、地图外、部署完成后及取消选择时不显示范围。覆盖层保留地形纹理和角色可读性，不参与地块拾取。


## 技能与撤退

主动技能技力充满（包括自动回复达标）时，在场干员显示金色轮廓亮光，以及金色菱形底板／黑色技能符号组成的头顶徽记。徽记带柔光、轻微缩放与上下浮动，朝向镜头并位于角色头顶上方。点击干员打开详情，点击高亮的技能图标按钮释放；技力不足、技能持续中或尚未开始战斗时按钮禁用，状态由图标与技力条表达。释放后就绪亮光消失，技能持续时间沿用脚下金色条；无主动技能的单位不显示就绪亮光。提示与动画使用战斗时钟，暂停冻结；待部署预览、离场与终局不显示提示。

已部署干员旁的“撤退”图标回收干员，返还部署费用的一半（向下取整，受费用上限限制）。卡片按原编队顺序恢复并显示再部署冷却，冷却期间禁止选择和重新部署；冷却结束后还需满足费用要求。待部署时角色旁的相同图标仅取消预览，不执行撤退或扣费。

技能图标由 appearance 的可选 skill_icon 字段提供，未配置时回退为角色头像；五名干员使用 content/ui/skill_icons 中对应的图集切片；头顶的通用金色徽记使用 actor_view 内的矢量素材。完整鼠标操作验证入口为 game/tests/operator_actions_test.gd，截图 temp/verification/operator_skill_ready.png，日志 temp/operator_actions.log。


## 出怪前路线预告

每组出怪前播放一次 2 秒路线预告：半透明红橙色引导线贴在地面，连通该组出生点与基地，连续高亮光束从出生点流向目标，扫过一次后淡出；预告完成才开始出怪。同组后续敌人保留原间隔，不逐个重复预告。不同路线可同时预告。

路线仍取 TileMap 编辑场景中的 Path2D，跟随地表高度。时序由 battle 产生 route_warnings 快照与 route_warning 事件，表现只按模拟时间显示，支持暂停、单步和倍速；重开、重载、终局和离开时清理。Level 的 route_warning_duration 当前为 2 秒；Wave.time 是期望的最早首怪时刻，若不足 2 秒则顺延至第 2 秒，后续组的时间保持不变。Art Test 使用同一引导线实现，模拟预告完成后再显示敌人。

验证入口 game/tests/route_warning_test.gd；日志 temp/route_warning.log，三种窗口截图 temp/verification/route_early_*.png、route_late_*.png。


顶部敌人进度／基地生命沿用原 Art Test 的图标样式：旗帜 ⚑＋进度、城堡 ♜＋剩余生命，Art Test 与 Game Test 共用格式，不以“敌人／基地”文字替代图标。


部署高亮使用 battle.deployment_check 的只读结果：绿色半透明覆盖层表示当前可部署格（同时检查地形、占用、费用、冷却与上限），橙色覆盖层仅在合法候选格显示攻击范围。取消或成功部署清除绿色和橙色覆盖层；点击在场干员时显示其实际朝向的橙色攻击范围及详情，取消选择、撤退或离场后隐藏；技能和撤退操作继续正常使用。


当前攻击范围（含干员所在格，随四向朝向旋转）：射手横向 3 格、朝向纵深 4 格；术师 3×3；近卫横向 1 格、朝向纵深 2 格。预览与实际判定均读取各自 stats.tres 的 range_cells。


角色朝向：当前立片原图默认朝左，所以部署朝右（0）时水平翻转、朝左（2）时保持原图；上／下沿用正背面姿态。待部署预览、在场待机／攻击和敌人共用同一映射。敌人出生首帧按所在路线段初始化朝向，后续按实际移动方向更新，不从世界原点推算。

部署卡片不显示悬浮文字提示。顶部菜单、倍速和暂停图标及按钮按原尺寸放大 1.5 倍，顶部中央进度图标与数字放大 1.2 倍；左下角 F3 按钮随窗口底边定位，操作提示与开始按钮为它留出横向空间。

角色表现统一相对逻辑格心下移 20 个视口像素，包含干员、敌人和待部署预览；血条、技能提示、接触阴影、战斗特效、角色拾取和附近操作按钮使用同一视觉锚点。视觉锚点沿原地面高度投影，逻辑格子、路线、地形高度及飞行高度不变，Art Test 共享该行为。附近的撤退／技能按钮在正常、悬浮、按下、禁用与就绪状态均使用无倾斜的正方形样式。

干员脚下使用青绿色半透明罗盘标识：淡圆面、圆环和朝向侧向外延伸的三角尖角。标识中心固定在角色的地形格心，相对此前跟随立片的版本上移约20px，在地面平面中随四向朝向旋转；待部署预览与在场干员共用，取代原先待部署的黄色点状方向箭头。标识使用带SVG纹理的水平3D Quad，启用场景深度测试；距地形高度约0.053，位于攻击预览填充（0.020）及边框之上，透明绘制优先级为3（攻击预览为2），前景地形、草丛或墙体可正常遮挡；撤退／离场时立即隐藏，敌人不显示干员罗盘。Art Test 使用同一实现。

五名干员均已配置主动技能及独立图标：近卫“锋刃”、重装“坚城”、射手“疾风连射”、术师“聚能爆破”、医疗“急救增幅”。技能数值和图标对应表见 content/ui/skill_icons/README.md。重装按受击充能，射手按有效攻击充能，其余自动回复；达到技力要求后点击干员右下方技能图标释放。图标在左侧详情和 Art Test/Skill 中保持一致。

常规界面不显示点击／拖动教学、技能就绪说明或“操作成功”等注释式文案。技能状态通过图标高亮、按钮禁用、技力条及持续倒计时表达；左侧仅保留干员数值和技能名称／功能。非法部署仍显示简短失败原因，后续有效选择或操作清除。


### 角色平移动画

共享actor_view_3d提供干员idle呼吸（周期2.4秒，上下幅度0.025世界单位）和敌人walk摆动（周期0.55秒，左右位移幅度0.012世界单位，绕脚下支点摆角约±2°）。干员沿镜头竖轴平移；敌人以轻微侧倾为主、少量横向位移为辅，旋转始终位于镜头平面内，保持billboard和原有尺寸；逻辑坐标、脚下罗盘与血条保持稳定。攻击姿态、敌人被阻挡及待部署预览不播放该平移。动画由advance_visual接收战斗时钟，暂停冻结、倍速同步，重开清空相位；Art Test的Battle页复用同一实现和预览时钟。

Game Test 默认编队位于 content/data/game_test_roster.tres，直接引用 character_011～015 的正式角色文件；Art Test 和固定数值自动化测试使用 test_roster.tres。scene_001 不保存 roster 或角色引用。正式 Player Mode 从存档读取当前可出战干员并注入所选关卡，1-1B（scene_0101B）固定由大星、小黄出战，其余旧关重打保留当前队伍。
