# Artist（美术）

## 开始前

- 从 [角色与章节大纲](../Human/GameContent.md) 和任务指定的剧情稿确认身份、场景和用途；后续明确修订优先，未规定的外观作为提案。
- 实际查看 [美术参考](../Human/ArtReference.jpg) 与指定的已确认素材，确定主体、画风、布局、规格和交付路径。需要接入游戏时同时读取 [程序角色](programmer.md)。

## 角色与敌人图集

- 采用精细高清 Q 版战术 RPG 插画，使用已确认素材保持角色身份、装备、配色与体型。敌人通过轮廓、材质、体型和装备区分职责。
- 交付 1024×1024 RGBA 透明 PNG，4×4 网格，每格 256×256；每行一个角色，空行保持透明。每格四边至少 10px 透明，相邻单元至少 20px 透明间隔；同行身体比例和脚底基线一致。
- 我方四列依次为 `idle_front_left`、`idle_back_left`、`attack_front_left`、`attack_back_left`；敌人前两列改为 `walk_front_left`、`walk_back_left`。front 显示脸和胸部，back 显示真实背面；敌人行走及攻击、治疗或施法动作应可辨认。
- 主体和装备完整入格，武器紧凑，不跨格或裁切；独立大型特效另行制作。画面不包含背景、地面阴影、底座、文字、UI、水印或网格。
- 按原图实际边界分区，等比缩放并统一锚点，避免直接等分切断主体。后处理只用于切片、透明边缘清理、缩放和排版；原图缺失的部分需修订或重新生成。

## 剧情背景

- 交付 1600×900、16:9 PNG 环境图；角色单独叠加，背景不含人物、动物、怪物、UI、文字或水印。
- 延续手绘战术科幻风格，保持可信透视、清晰大色块、柔和过渡和克制光效。每张有明确视觉重点与少量成组叙事元素；远景简化，为立绘和对白留出低对比区域。
- 同一章节统一材质、色调和建筑风格，各场景保留独立构图重点；留白仍有光影和空间关系，布局不必固定左右位置。
- 地面保留适量结构与物件，默认干燥哑光；剧情需要湿地或水面时保持反射局部、简化、克制。避免满屏颗粒、均匀微细节、过量道具和大面积反光。
- 使用 imagegen 生成；按章节目录保存，文件名包含章节、关卡、场景和版本。

## 交付与验收

- 原始素材保留在 `Human/StarterContent/`；生成版本保留旧版，PNG 旁保存实际完整提示词及参考来源。图集清单记录行号、身份、源图、处理和验证结果；正式接入按 [程序角色](programmer.md) 的资源归属整理。
- 查看最终 PNG，确认画面、提示词、清单和目标路径对应同一资产。图集需自动检查尺寸、透明间隔与空行，并按运行时单元逐格目视检查身份、姿态、朝向、轮廓和完整武器；只将实际检查过的约束标为通过。
- 接入后在 [Art Test](../devtools/art_test/README.md) 或 [Story Test](../devtools/story_test/README.md) 检查；涉及战场共享表现时补充 [Game Test](../devtools/game_test/README.md)。
