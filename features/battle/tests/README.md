# Battle 自动化测试

所有用例通过 battle 公共接口执行，无 Control、几何战场或美术资源依赖，可使用 --headless 运行。

- battle_test.gd：基础规则和边界检查，包括部署、阻挡、伤害、治疗、技能倍率、暂停单步、终局和重置。
- scenario_test.gd：从已移除的 Logic Test 保留的18个命令回放场景；scenario_fixtures.gd 保存配置，scenario_replay.gd 按固定时刻提交命令并观察快照／事件。每个场景另按逐帧分片重放，比对最终状态一致。
- 游戏层的 game/tests/battle_integration_test.gd 继续负责地图与组装、固定获胜／空场失败、重置与生命周期；game/tests/battle_visual_test.gd 验证实际输入与画面。手动验证统一使用 Game Test。

```powershell
& $env:GODOT_PATH --headless --path . --script res://features/battle/tests/battle_test.gd
& $env:GODOT_PATH --headless --path . --script res://features/battle/tests/scenario_test.gd
& $env:GODOT_PATH --headless --path . --script res://game/tests/battle_integration_test.gd
```

日志和截图放入根目录 temp/。以下为纯规则测试场景及约定，不提供单独测试界面。

## 场景与验收

| 场景组 | 用例 | 验证内容 |
| --- | --- | --- |
| 1. 部署与战场管理 | 合法性、返费与再部署 | 地形、占位、重复部署、上限、费用、非法命令不扣费、撤退返费、冷却后再部署 |
| 2. 远程交火与对空 | 最后部署优先与走停；方向与对空 | 射程与朝向、最新部署索敌、动作停步、冷却移动、飞行不可阻挡、射手对空 |
| 3. 近战与阻挡 | 阻挡2、溢出与撤退释放；死亡释放与不返费 | 容量与抵达顺序、近战反击、多余敌人前进、撤退与死亡释放阻挡 |
| 4. 伤害与治疗 | 物理、法术、真实；治疗与生命上限 | 100攻击对80防御/60法抗分别造成20/40/100伤害；受伤治疗、不溢出 |
| 5. 被动与主动技能 | 三普攻后强化；auto / attack / hit | 第4/8/12击强化；三种技力来源、释放条件、持续攻击强化、不叠加、结束恢复 |
| 6. 路线、波次与胜负 | 双路线与延迟波次；基地耗尽 | 转弯、后续波次阻止提前胜利、存活漏怪后胜利、基地归零失败、终局冻结 |
| 7. 综合防守 | 预设获胜；缺少对空；空场失败 | 近卫、射手、医疗和技能协作；两架飞行敌人漏过；空场失败 |

### 统一规则

- 地图以格子中心为坐标。敌人沿配置折线路径连续移动，干员在格子中心。朝向编号为右0、下1、左2、上3，攻击模板随朝向旋转；格子边界计入范围。
- 近战部署地面，远程和医疗部署高台。编队每个条目同时只能有一个在场实例；不同条目可使用相同数值。
- 近战默认攻击自身格与前方一格，优先自己阻挡的敌人；其次与普通远程一样，选择距离终点剩余路程最短的合法目标。并列取最小单位ID；默认单体攻击，阻挡数不等于同时攻击目标数。
- 地面敌人进入干员格时按模拟抵达顺序分配容量；同一模拟帧按稳定敌人ID处理。超过阻挡上限的敌人继续移动；飞行忽略阻挡。已建立的阻挡保持至任一方离场。
- 近战敌人只攻击阻挡者。远程敌人被阻挡时优先攻击阻挡者，否则攻击射程内最新部署的存活干员。
- 远程敌人仅在攻击动作期间停步，冷却期间继续移动；被阻挡时一直停步。出手锁定目标，命中前目标死亡或撤退则落空，不换目标；目标仅离开范围不取消已锁定攻击。
- 攻击间隔从开始出手计时，`windup` 后直接结算，没有弹道；`0 ≤ windup ≤ interval`。零动作时长即刻命中。固定帧内按敌方动作、移动阻挡、我方动作、离场与胜负顺序结算；致死后生命为零的单位立即不能成为新目标。
- 物理伤害：`max(攻击力－防御, 攻击力×5%)`。法术伤害：`攻击力×(1－clamp(法抗,0,95)/100)`。真实伤害：攻击力。保留浮点，不在规则层取整。
- 医疗只选择范围内受伤存活友军，优先生命比例最低者，并列取最小ID；治疗忽略防御法抗，上限为缺失生命，不复活、不攻击敌人。医疗允许治疗自己。
- 被动每三次有效普通攻击后强化下一击：第4、8、12击默认200%攻击力。无目标、锁定目标已离场造成的落空不计数；换目标和目标空档保留计数。撤退、死亡、重新部署和重置清空。
- 每个主动技能选择一种技力来源：auto 每秒1点；attack 每次有效攻击/治疗1点；hit 每次受到有效攻击1点。达到上限后才能手动释放，释放清空技力；持续期间攻击力乘配置倍率、不回复、不叠加，结束后恢复基础数值。主动倍率和被动倍率相乘。
- 费用在战斗进行时持续回复，不超过上限。主动撤退返还本次部署费用50%，向下取整；死亡不返费。两者均进入配置的再部署冷却。再部署费用不递增，新实例满生命、初始技力、全新计数和ID。
- 所有配置波次生成完、在场敌人全部处理完且基地生命大于零才胜利；基地生命归零立即失败。漏怪按敌人配置扣血。终局停止模拟且拒绝部署、撤退和技能命令。
