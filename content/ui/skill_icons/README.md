# 技能图标

来源：`Human/StarterContent/icon/skill-atlas-01.png`，正式资源使用本目录的 `atlas.png` 副本。

图集为 1254×1254，按 4×4 等分，单格 313.5×313.5；AtlasTexture 保留精确浮点区域并启用 `filter_clip`，避免采样串格。`icon_01` 至 `icon_16` 按从左到右、从上到下编号。

角色外观的 `skill_icon` 指向同一套切片，不引用 Human 原件。技能名称、数值和说明以各角色 `stats.tres` 的技能资源为准；素材可在 Art Test → Skill 浏览。
