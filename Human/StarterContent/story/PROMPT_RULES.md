# 剧情背景图 Prompt 规则

## 内容与输出

- 以 `Human/GameContent.md` 的正式剧情为依据，按剧情场景分别生成；场景中未规定的建筑、道具和神器外观属于设计提案，不自动成为正式设定。
- 使用 imagegen 生成，每张交付 1600×900 PNG，16:9，完整画面，无边框。
- 仅生成环境背景，不加入人物、宠物、怪物、人形剪影、UI、对白、文字或水印，角色由游戏另外叠加。
- 本目录按 `chapter01` 等章节目录保存，文件名包含章节、关卡、场景英文名和版本号；修改生成新版本。

## 画风

- 延续日系战术科幻游戏的手绘场景方向：可信透视、空间层次、克制配色和电影感光影。
- 采用清晰的大色块、柔和的明暗过渡及选择性边缘刻画，避免摄影式微细节、满屏颗粒和均匀铺设的材质噪声。
- 同一章节维持统一的材质、色调、异常节点语言和建筑风格，但每个场景应有自己的构图重点。

## 构图、留白与细节密度

- 必须有主有次：一个明确的视觉重点，少量次要叙事元素，远景降低对比与细节。
- 留白是有色调、光影和空间关系的安静区域，不要求纯色，也不能变成整片毫无内容的空地。
- 为角色立绘和底部对白保留适当的低对比区域，不固定所有画面都采用同一种左右布局。
- 地面保留适量、有用途的元素，例如路沿、少量石板接缝、脚印、岩石、成组道具；避免过空，也避免道具散落满地。
- 道具应成组集中于少数位置，服务地点识别与叙事。不要不断添加箱子、缆绳、栏杆、碎石来填满画面。
- 重点区域可适度细化；其余区域用概括的形体表达，不要每个部位都同样精细。

## 地面、材质与光效

- 地面默认干燥、哑光；不要惯性加入雨后积水、镜面地板或大面积反射灯光。
- 剧情需要水面或湿地时，反射局部、简化、克制，避免遍布高光碎点和长条彩色光带。
- 沙地、雪地、石墙用大块形体表达，避免密集沙粒、碎石点、裂纹、细波纹及颗粒滤镜。
- 窗灯、异常节点和神器的光只在重点附近起作用，避免全画面泛光、粒子、闪电网络或发光地面路线。

## 已确认的反馈

- 第一章「家中异常」的主次和细节分布是正向参考。
- 第一版「路边救援」细节太满，碎枝、反光、建筑纹理争抢注意力。
- 随后的留白版本地面过空，需要适量环境元素。
- 第二章地面灯光反射过多，元素也略多；后续应减少。
- 第三章之后继续强调安静区域，避免到处都是颗粒感。

## 通用 Prompt 模板

```text
用途：日系战术科幻游戏的剧情环境背景。
输出：1600×900，16:9，PNG，画面铺满。
剧情依据：[章节、场景、正在发生的事件]。
地点与时间：[具体环境、时段、天气]。
视觉重点：[一个主要焦点及所在位置]。
次要元素：[少量、成组、有叙事用途的环境元素]。
构图：可信透视与前中后景；为立绘和对白保留适当的低对比区域；
留白仍有光影和空间，地面有适量结构与物件，不成为大片空地。
画风：精致手绘动漫场景，大色块，柔和过渡，选择性细节，远景简化。
材质：默认干燥哑光，控制细碎纹理，不使用满屏颗粒。
光影：[主光源、克制配色]；特殊光效集中于焦点附近。
避免：均匀高细节、摄影微纹理、密集碎屑、过量道具、大面积地面反光、
满屏粒子、无内容的空地、人物、动物、怪物、UI、文字、水印、边框。
```
