## 剧情表
| 章节 | 战斗 | 剧情总结 |
|---|---|---|
| **第一章：上海** | **1. 家中异常** | 上海突然停电，家中异常来袭，大星与宠物猫小黄共同迎战。小黄为了保护大星，被异常节点吞噬失踪。 |
|  | **2. 路边救援** | 节点管控局队长阿五与副队长胡胡前来处理事故，并与大星赶往主节点。途中众人在路边发现被怪物围困的医院医生月月，击退怪物将她救下。 |
|  | **3. 东方明珠主节点** | 众人来到东方明珠，上海主节点正在失控，大量怪物不断出现。众人守住修复行动，恢复城市并定位到小黄的信号位于海洋区域。 |
| **第二章：海洋** | **4. 港口防卫** | 众人准备出海寻找小黄，却遭遇异常怪物袭击港口。船长 Tiger 与众人共同守住港口，并负责带他们出海。 |
|  | **5. 海上袭击** | 航行途中遭遇异常风暴，并遇见乘私人游艇出行的董事长 Sugar。双方联手突破怪物包围，Sugar 带着游艇和资源加入行动。 |
|  | **6. 海洋节点** | 众人在海洋节点深处终于找到小黄，并击退怪物将它救回。小黄伤势严重，月月判断只有传说中的天山雪莲才能救它。 |
| **第三章：高山** | **7. 山路突破** | 众人为寻找天山雪莲进入川西高山，却被节点异常封锁道路。途中遇见保镖前哥，众人联手突破怪物封锁继续前进。 |
|  | **8. 高山营地** | 众人在暴雪中来到山间营地，遇见米其林主厨冰冰。怪物袭击营地，冰冰协助众人守住防线并加入队伍。 |
|  | **9. 雪山节点** | 众人突破雪山节点，取得天山雪莲并成功救活小黄。与此同时世界各地异常全面恶化，众人得知沙漠中存在能够消灭异常的古代神器。 |
| **第四章：沙漠** | **10. 绿洲异常** | 众人前往沙漠寻找神器，却在异常中失去方向。占星师浮白利用星象找到古代遗迹的位置，并帮助众人击退绿洲中的怪物。 |
|  | **11. 地下遗迹** | 众人进入古代遗迹，遇见研究节点文明的学者 EE。大量异常怪物突然向遗迹聚集，众人判断 Boss 的目标也是神器。 |
|  | **12. 神器争夺** | Boss 的部队大举进攻遗迹，众人拼尽全力成功取得神器。此时阿五收到紧急通讯，众人才发现沙漠袭击只是诱饵，Boss 已趁管控局防守空虚突袭总部。 |
| **终章：节点管控局** | **13. 总部外围** | 众人带着神器紧急返回，发现节点管控局已经被 Boss 和怪物占领。所有伙伴集结，强行突破总部外围防线。 |
|  | **14. 管控局内部** | 阿五与胡胡带领众人深入总部，一边营救人员一边追击 Boss。众人发现 Boss 声东击西的真正目的，是夺取管控局中央节点。 |
|  | **15. 中央节点** | Boss 已经侵入中央节点，企图让异常扩散至整个世界。大星与十名伙伴利用刚取得的神器展开最终决战，击败 Boss 并终结节点异常。 |
| **尾声** | **回家** | 危机结束，小黄完全康复，众人回到上海。11名伙伴齐聚大星家，一起庆祝生日，为冒险画上句号。 |

## 战斗表

| 关卡 | 战斗特色 | 关键机制 / 难点 | 推荐解法 | 重点角色 |
|---|---|---|---|---|
| **1. 家中异常** | 小规模教学战 | 狭窄地图、少量敌人；后期突然出现突破口 | 大星正面阻挡，小黄利用快速部署救场、处理漏怪 | **大星、小黄** |
| **2. 路边救援** | 多路线救援 | 月月被困，敌人从两条街道包围；必须同时守线和救人 | 胡胡低费快速展开防线，阿五远程清理高威胁目标 | **阿五、胡胡** |
| **3. 东方明珠主节点** | 长时间防守 | 节点修复需要时间，敌人持续加强，并出现远程怪 | 胡胡负责前期回费，阿五处理精英，月月持续治疗前排 | **月月**首次可用 |
| **4. 港口防卫** | 大量敌人冲线 | 港口道路狭窄，大批低血量敌人连续冲锋 | Tiger堵住关键路口，让后排安心输出 | **Tiger** |
| **5. 海上袭击** | 多入口 + 临时路线变化 | 海浪会周期性改变敌人进攻路线，容易突然漏怪 | Sugar快速部署、回费，在新路线出现后迅速补防 | **Sugar** |
| **6. 海洋节点** | Boss救援战 | 必须一边对抗Boss，一边保护受伤的小黄；敌人会绕后 | Tiger抗住Boss，Sugar快速补位，阿五远程击破关键敌人 | **海洋队伍综合教学** |
| **7. 山路突破** | 高压单线战 | 山路狭窄，敌人数量不多但单体非常强 | 前哥站在最危险的位置持续输出，以高生存能力硬扛精英 | **前哥** |
| **8. 高山营地** | 全图持续掉血 | 暴雪使所有角色周期性受伤，同时多路线出现敌人 | 冰冰群体治疗维持整条战线，月月负责单点急救 | **冰冰** |
| **9. 雪山节点** | 生存 + 限时目标 | 必须保护采集雪莲的NPC/装置；暴雪与强敌同时施压 | Tiger守核心，冰冰群疗，前哥清理高威胁敌人 | **高山队伍综合战** |
| **10. 绿洲异常** | 视野与减速战 | 沙尘暴降低攻击范围，快速敌人从多个方向出现 | 浮白利用法术减速与范围攻击，把高速敌人控制在火力区 | **浮白** |
| **11. 地下遗迹** | 高甲敌人 | 古代守卫防御、法抗较高，普通输出效率下降 | EE削弱敌人防御和法抗，再让大星、阿五、浮白集中输出 | **EE** |
| **12. 神器争夺** | 波次攻防转换 | 先守神器，随后Boss军队从多方向强攻；精英大量出现 | EE先削弱，浮白群控，Tiger顶线，双先锋维持部署资源 | **浮白 + EE组合** |
| **13. 总部外围** | 全角色自由编队 | 三条路线同时遭受攻击，第一次要求玩家自行搭配完整阵容 | 毛毛/Sugar负责两路前期，Tiger守主路，远程与治疗分区支援 | **全员编队** |
| **14. 管控局内部** | 多阶段地图 | Boss不断关闭通道、改变路线；某些区域需要快速重新布阵 | 小黄发挥快速再部署优势，随时救场；Sugar负责快速补费用重新铺阵 | **小黄重新成为核心** |
| **15. 中央节点** | 最终Boss战 | Boss拥有多个阶段：召怪、范围攻击、突破防线；神器需要充能 | 第一阶段稳守，第二阶段EE削弱+浮白控制，第三阶段全员保护神器完成充能并集中爆发 | **11人最终协作** |
